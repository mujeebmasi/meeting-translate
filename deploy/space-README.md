# Meet Translate

Video meetings where people speaking Hindi, Telugu, Tamil or Kannada are
heard in English: live captions in under a second, and a spoken English
voice.

Code, design and measurements: https://github.com/mujeebmasi/meeting-translate

Creating a meeting needs an access code. If the page takes a minute to load,
the server was asleep and is starting up.
